# team_software_project
Accessing and Exploring system components to create a software product.
This project focuses on improving the lecturer review system at Pentecost University, Accra, Ghana. The system is designed to monitor lecturers based on their lecture schedules, student feedback, and course loads (including the specific courses occupied and the total number of courses per semester). The primary objective is to enhance the accuracy of record-keeping and overall performance tracking within the institution.
